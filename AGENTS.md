# Инструкции для агента

## Назначение проекта

Это демонстрационная ИИ-среда ACME Labs.
Она используется для подготовки рабочих документов по запуску нового направления.

## Структура

- `00-context/` — исходные материалы и источники контекста
- `01-rules/` — правила результата и ограничения
- `02-scenarios/` — повторяемые сценарии
- `03-outputs/` — результаты прогонов
- `04-decisions/` — карточки решений

## Правила работы

1. Не менять исходные материалы в `00-context/` без явной команды.
2. Новые результаты сохранять в `03-outputs/`.
3. Новые сценарии сохранять в `02-scenarios/`.
4. Перед фиксацией изменений показывать diff.
5. Каждый commit должен описывать смысл изменения.
6. Не добавлять чувствительные данные, ключи, токены и приватные файлы.
7. Если данных не хватает, не придумывать факты, а указать пробелы.

## Формат commit message

Использовать короткие сообщения:

- `add first working context`
- `update output rules`
- `add weekly launch scenario`
- `save first scenario run`
