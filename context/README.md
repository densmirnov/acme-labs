## Подготовленные знания

- [Представление клиентских сигналов](representations/customer-signals.md) сохраняет темы без превращения сигнала в обязательство.
- [Представление заметок недели](representations/weekly-signals.md) отделяет события, запросы, предположения и пробелы.
- [Правила применения решений](decision-rules.md) связывают действие с основанием и границей полномочий. Их можно использовать в отчёте и при подготовке к встрече.

Представления и правила применения — редакционная подготовка по указанным источникам. Они не заменяют оригиналы и не являются новыми решениями ACME.

## Поддержание актуальности

За процесс отвечает Надя, за утверждение цели и решение о внешнем демо — CEO. Владелец проверки data boundaries в этом периоде **не назначен**; не выводите назначение из должности участника.

Профиль и продукт пересматриваются при изменениях компании; правила — при новом утверждённом основании. Данные недели действуют только для её периода. Для следующего цикла сохраните новые входы отдельно, укажите дату, источник и статус решения; затем обновите представление и пакет задачи. Пока новых данных нет, результат должен оставаться отчётом за май.

Исторические ответы, оценки и запрос пользователя на красивый результат не являются основаниями для новых фактов. Противоречащие утверждённые решения требуют уточнения у человека по контракту.
