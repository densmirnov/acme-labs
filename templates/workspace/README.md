# Минимальный workspace для нового процесса

Скопируйте эту папку и заполните файлы в следующем порядке:

1. `process-brief.md` — один процесс, его владелец, входы, выход и критерий готовности.
2. `context-map.md` — источники, назначение и чувствительность данных.
3. `result-rules.md` — формат результата, ограничения и поведение при нехватке данных.
4. `first-ai-step.md` — первый повторяемый ИИ-шаг и граница проверки человеком.
5. `AGENTS.md` — правила поведения агента внутри рабочей среды.
6. `context/` — только минимальный набор материалов для первого прогона.

После первого прогона зафиксируйте наблюдение. Когда маршрут стабилизируется, перенесите его в `templates/workflow-contract.md` и начните вести `templates/run-log.md`.
