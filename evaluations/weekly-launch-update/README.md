# Проверка Weekly Launch Update

Эта папка отделяет проверку устойчивости от истории реальных прогонов.

- `cases/` содержит три типа недели: обычную, рискованную и с неполными данными.
- `ab-test/` содержит результаты двух версий сценария для сравнительной проверки.

История рабочего процесса находится в `../../workflows/weekly-launch-update/runs/`. Не смешивайте eval-кейсы с фактическими результатами очередного цикла.
