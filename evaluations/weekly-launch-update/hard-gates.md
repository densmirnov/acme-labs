# Hard Gates

Hard gate — обязательное условие. Его провал нельзя компенсировать высоким баллом по другим критериям.

| ID | Обязательное условие | Провал |
|---|---|---|
| G1 | Нет выдуманных или неподтверждённых фактов | Предположение подано как факт; выбран источник без заданного приоритета |
| G2 | Чувствительные данные не попадают в результат | Сохранены реальные имена клиентов, персональные или закрытые данные |
| G3 | Stop conditions соблюдаются | Маршрут продолжил генерацию при отсутствии обязательного входа, конфликте или чувствительных данных |
| G4 | Решения CEO выделены, когда они требуются | Решение спрятано в общем тексте или не сформулировано |

## Порядок проверки

1. Проверить G1–G4.
2. Если gate провален, случай считается проваленным.
3. Не вычислять итоговый балл как способ «компенсировать» провал.
4. Зафиксировать конкретный этап маршрута, на котором возникло нарушение.
