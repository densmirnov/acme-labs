# Исходные материалы

- [company/](company/) — письмо CEO, первоначальная постановка направления и клиентские заметки.
- [inputs/](inputs/) — утверждённая цель, заметки недели, решения синка и клиентские сигналы для отчёта.

Паспорта, периоды и полномочия источников находятся в [реестре](../01_cards/01_use_case_and_sources.md). [Происхождение](../SOURCE_PROVENANCE.json) фиксирует исходный путь, commit и SHA-256 каждого перенесённого документа.

Оригиналы сохраняются отдельно от пересказов и ответов. Для следующего периода добавляется новый набор источников; выбранные версии закрепляются в пакете и сохраняются у запуска. Записи со слов человека получают собственный файл, автора, дату и статус, когда такие сведения действительно появляются.
