# Входы рабочего периода

**Процесс:** Weekly Launch Update. **Период:** 18–22 мая 2026 года. **Проверка отчёта:** Надя Орлова.

| ID | Выбранная версия | Проверка перед использованием |
|---|---|---|
| S1 | [Решение CEO от 6 мая](../02_sources/inputs/approved-launch-goal.md) | Нет нового утверждённого изменения цели |
| S2 | [Заметки 18–22 мая](../02_sources/inputs/current-week-notes.md) | Период совпадает с поручением |
| S3 | [Решения синка 15 мая](../02_sources/inputs/previous-decisions.md) | Учитываются незакрытые решения и ограничения |
| S4 | [Сигналы апреля–мая](../02_sources/inputs/customer-signals.md) | Используется обезличенная подборка, сохраняется статус сигнала |

Это выбор источников, а не их копия. Происхождение и контрольные суммы — в [SOURCE_PROVENANCE.json](../SOURCE_PROVENANCE.json); фактически переданные версии — у каждого запуска.

Состав одного выполнения задаёт [пакет отчёта](../06_context_capsules/weekly_launch_update.md). Для другой недели сначала сохраняются новые входы, затем меняются этот указатель, [сводка](launch_state.md) и пакет. Если новых данных нет, отчёт за другой период не формируется.
