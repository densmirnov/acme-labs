# Start here

This is a synthetic example of the folder a workshop participant can receive from the Context Layer Builder. It does not replace the mature ACME workflow. It makes the context layers visible and points to the existing source-of-truth files instead of copying them.

## Read order

1. `AGENTS.md`
2. `01_cards/01_use_case_and_sources.md`
3. `01_cards/02_context_layer_blueprint.md`
4. `01_cards/03_use_and_improve.md`
5. `06_context_capsules/weekly_launch_update.md`

## What is already here

The use case, source map, layer blueprint, and one task capsule are filled with synthetic ACME material. The original files remain in `../context/`, `../policies/`, and `../workflows/`.

## What this demonstrates

- a participant can begin with a small, legible skeleton;
- sources, representations, canonical context, current context, capsules, and runs have different roles;
- an agent can receive only the context needed for one task;
- improvements come from preserved observations, not from silently rewriting old output.

No run was performed by the Context Layer Builder.
