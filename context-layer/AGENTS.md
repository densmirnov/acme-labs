# Context layer instructions

These rules apply only inside `context-layer/` and complement the repository-level `AGENTS.md`.

1. Read `00_START_HERE.md` and the three files in `01_cards/` before using this layer.
2. Treat files in `02_sources/` as source pointers or participant-provided notes, not automatically approved truth.
3. Preserve provenance when creating a representation; link to the source and state what changed.
4. Prefer `04_canonical_context/` for stable shared rules and `05_current_context/` for period-specific inputs.
5. Build a task-specific capsule in `06_context_capsules/` instead of loading the entire repository.
6. Do not invent missing facts, permissions, dates, or metrics.
7. Stop when a required input is absent or when sources conflict without a stated priority.
8. Save new execution outputs under `07_runs/`; never overwrite source material or prior runs.
