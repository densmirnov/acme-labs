# Контекстный слой ACME Labs

Точка продолжения работы — [00_START_HERE.md](00_START_HERE.md).

| Раздел | Рабочие материалы |
|---|---|
| [01_cards](01_cards/README.md) | Задача, реестр источников, схема знаний и журнал применения |
| [02_sources](02_sources/README.md) | Поручение CEO, клиентские заметки, первоначальная цель и четыре входа отчётного периода |
| [03_representations](03_representations/README.md) | Темы клиентских сигналов и статусы сведений недели |
| [04_canonical_context](04_canonical_context/README.md) | Компания, продукт, роли, политики и правила применения решений |
| [05_current_context](05_current_context/README.md) | Состояние направления и состав активного периода |
| [06_context_capsules](06_context_capsules/README.md) | Пакет недельного отчёта: поручение, выбранные входы, критерии и ограничения |
| [07_runs](07_runs/README.md) | История процесса и выполненные серии со снимками входов |

Карта источников находится в первом документе, порядок обновления — во втором, фактические версии и результаты — в третьем. Карточки ссылаются на материалы, а не заменяют их содержимое.

Политики и справочные документы поддерживаются в `04_canonical_context/`, оригиналы рабочих сообщений — в `02_sources/`. Происхождение перенесённых документов зафиксировано в [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json). Снимки внутри запусков неизменяемы и отражают именно использованные тогда входы.
