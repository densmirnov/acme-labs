# ACME context layer

This folder is a worked example of the starter structure produced by Context Layer Builder. Start with [`00_START_HERE.md`](00_START_HERE.md), then read [`AGENTS.md`](AGENTS.md) and the three cards in [`01_cards/`](01_cards/).

Every numbered folder has its own `README.md`. It explains what belongs there, what must not be assumed, and how the ACME example connects to the existing repository.
