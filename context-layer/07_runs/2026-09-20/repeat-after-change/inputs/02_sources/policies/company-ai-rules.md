# Правила работы с ИИ в ACME Labs

## Назначение

Этот файл задаёт базовые правила работы с ИИ внутри демонстрационной среды ACME Labs.

## Общий принцип

ИИ используется для ускорения работы с контекстом, сценариями и результатами. Он не заменяет владельца решения и не должен скрывать неопределённость.

## Что можно использовать

Можно использовать:

- публичные материалы компании;
- обезличенные заметки клиентов;
- внутренние документы без чувствительных данных;
- шаблоны документов;
- рабочие сценарии;
- результаты предыдущих прогонов;
- явно сформулированные правила и ограничения.

## Что использовать осторожно

Требует осторожности:

- клиентские интервью;
- финансовые данные;
- персональные данные сотрудников;
- закрытые стратегические документы;
- документы под NDA;
- данные, по которым можно восстановить конкретного клиента.

## Что нельзя использовать без проверки

Нельзя без отдельного разрешения:

- реальные имена клиентов;
- персональные данные;
- пароли, ключи доступа, токены;
- закрытые финансовые показатели;
- юридически чувствительные документы;
- конфиденциальные условия контрактов.

## Правило чувствительных данных

Если материал нельзя бездумно отправить коллеге внутри компании, его нельзя автоматически считать пригодным для ИИ-среды.

## Требования к результатам

Любой результат ИИ должен:

- явно опираться на предоставленный контекст;
- не придумывать факты;
- разделять факты, выводы и гипотезы;
- указывать пробелы в данных;
- быть пригодным для проверки человеком.

## При нехватке данных

Если данных недостаточно, ИИ должен:

1. явно указать, каких данных не хватает;
2. не заполнять пробелы выдуманными фактами;
3. предложить вопросы для уточнения;
4. отделить уверенные выводы от гипотез.
