# Минимальный skill-пакет: карта файлов

```text
weekly-launch-update/
  SKILL.md
  references/
    workflow-contract.md
    criteria.md
  examples/
    normal-week.md
    risky-week.md
    incomplete-data.md
```

## Когда упаковывать

- процесс действительно повторяется;
- входы достаточно предсказуемы;
- шаги можно описать без участия автора;
- выход имеет стабильный формат;
- качество можно проверить;
- сценарий потенциально полезен не только Наде.

## Связь с рабочим репозиторием

Готовый пример пакета находится в `05-skills/weekly-launch-update/`.

- `SKILL.md` — когда и как использовать навык;
- `references/` — подробная логика и критерии;
- `examples/` — обычный и сложный случаи;
- `openapi/` — необязательный пример интеграции, который не нужен для файлового сценария.
