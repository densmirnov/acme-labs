# Примеры результатов

[Первый executive brief](executive-brief-first-run.md) — сохранённый черновик по исходному письму CEO. Предложенные в нём сегменты, метрики, ресурсы и следующие шаги не являются утверждёнными решениями компании.

Другие учебные результаты:

- [Версии Weekly Launch Update](../workflows/weekly-launch-update/runs/comparison.md) — изменение workflow от 0.1 к 0.2.
- [Проверочные случаи и оценки](../evaluations/weekly-launch-update/README.md) — разбор поведения на пяти типах входов.

Эти материалы полезны для разбора после собственного запуска. Не включайте их в источники слепой проверки и не выдавайте демонстрационные оценки за свежие измерения. Текущий [воркшоп](../workshops/context-layer/README.md) предлагает сохранить собственные попытки и проверить одну правку на том же поручении.
