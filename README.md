# ACME Labs: демонстрационная ИИ-среда

## Назначение

ACME Labs — вымышленная SaaS-компания и пример файловой ИИ-среды для работы с повторяемыми бизнес-процессами.

Пакет показывает, как из разрозненных документов, правил, сценариев и результатов собирается рабочий контекст для ИИ.

Сквозная задача: **запуск нового продуктового направления за 90 дней**.

Главный оператор системы: **Надя Орлова, Product Lead**.

## Как использовать этот пакет

1. Откройте папку `acme-labs` в выбранной рабочей среде.
2. Начните с чтения файлов в `00-context/`.
3. Затем добавьте правила из `01-rules/`.
4. Используйте сценарий из `02-scenarios/`.
5. Сравните результаты в `03-outputs/`.
6. Для решения о следующем шаге используйте `04-decisions/decision-card-template.md`.
7. Полный пример процесса weekly launch update находится в `07-workflow-example/`.

## Уровни контекста

### Личный уровень

Материалы и правила, которые помогают Наде выполнять свою работу:

- роль Нади;
- личные рабочие правила;
- черновики сценариев;
- первые результаты прогонов.

### Проектный уровень

Материалы, связанные с запуском нового направления:

- цель запуска;
- заметки клиентов;
- обзор продукта;
- еженедельные обновления;
- проектные решения.

### Общий уровень

Материалы, которые потенциально можно передавать команде:

- правила работы с ИИ;
- шаблоны результатов;
- повторяемые сценарии;
- карточки решений.

## Минимальный первый запрос

```text
Прочитай README.md, файлы из 00-context и правила из 01-rules.

Задача: подготовить executive brief по запуску нового направления ACME Labs.

Используй только предоставленный контекст. Если данных не хватает, явно укажи пробелы.

Формат результата: краткое резюме, цель запуска, ключевые сигналы клиентов, риски, решения, которые нужны от CEO, следующие шаги.
```

## Главное правило

Не пытайтесь автоматизировать систему до того, как появился повторяемый сценарий и понятный критерий качества.
