# Weekly Launch Update

Надя Орлова готовит отчёт о запуске AI Workspace Layer для CEO и команды перед еженедельным синком. Отчёт содержит статус, изменения, до трёх приоритетных рисков и решения, требующие участия руководителя.

**Контракт:** 0.2. **Период подготовленных входов:** 18–22 мая 2026 года. **Режим:** ИИ готовит черновик, Надя проверяет и утверждает его перед отправкой.

## Выполнить процесс

1. Открыть [пакет контекста](../../context-layer/06_context_capsules/weekly_launch_update.md) и [контракт](workflow-contract.md).
2. Проверить наличие четырёх обязательных входов, их период и допустимость данных.
3. Подготовить черновик по выбранным источникам. При срабатывании stop condition сохранить причину остановки и вопрос человеку.
4. Сохранить запрос, использованные версии входов, ответ и проверку в новой папке `../../context-layer/07_runs/weekly-launch-update/<run-id>/`.
5. Добавить фактическое наблюдение в [журнал](../../context-layer/07_runs/weekly-launch-update/run-log.md). Передать черновик Наде для проверки фактов, приоритетов и решений.

Версия контракта, редакция пакета и ID прогона учитываются отдельно. `../../context-layer/07_runs/weekly-launch-update/v0.1/` и `../../context-layer/07_runs/weekly-launch-update/v0.2/` — существующие записи, их не перезаписывают при повторном выполнении.

## Следующий период

Сохранить отдельный набор входов с новым периодом, источниками и статусами решений. Обновить пакет и зависимые представления, сверить [состояние направления](../../context-layer/05_current_context/launch_state.md). Предыдущие входы и ответы остаются доступными для проверки.

В новом пакете явно выбрать решения прошлого цикла, открытые вопросы и прошлый финальный отчёт, если он доступен. Если финального отчёта нет, указать пробел и сравнивать только с доступными решениями.

## Изменение процесса

Зафиксировать наблюдение по ответу, основание для правки и ожидаемый эффект. Сохранить использованные версии, изменить нужный источник, представление, пакет или контракт, затем выполнить новый прогон. Для изменения логики контракта нужна новая версия и отдельная проверочная серия.
