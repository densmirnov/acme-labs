# Правила формата результата

## Общий стиль

Пиши кратко, структурированно и деловым языком.

Не используй рекламный тон, общие фразы и необоснованные обещания.

## Базовая структура executive brief

Для управленческого brief используй структуру:

1. Краткое резюме
2. Цель
3. На какие данные опираемся
4. Ключевые сигналы
5. Риски
6. Открытые вопросы
7. Решения, которые нужны от CEO / команды
8. Следующие шаги

## Базовая структура weekly update

Для еженедельного обновления используй структуру:

1. Статус недели
2. Что изменилось с прошлого обновления
3. Главные достижения
4. Три главных риска
5. Блокеры
6. Решения, которые нужны
7. Следующие шаги

## Требования к качеству

Результат считается хорошим, если:

- его можно использовать без полного переписывания;
- из него понятно, что произошло;
- ясно, какие решения требуются;
- видны риски и открытые вопросы;
- нет выдуманных фактов;
- структура повторяема.

## Если данных не хватает

Добавь отдельный блок:

```text
Пробелы в данных:
- ...
```

Не скрывай неопределённость внутри уверенного текста.

## Запрещённые паттерны

Не писать:

- “это революционное направление” без доказательств;
- “клиенты точно готовы платить”, если в контексте нет подтверждения;
- “риск низкий”, если риск не оценён;
- длинные вступления;
- абстрактные рекомендации без следующего действия.
